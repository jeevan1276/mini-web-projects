# Mini Web Projects

A collection of small web and dweb projects built for experimentation, learning, and sharing.

## Projects

Each project should live in its own directory and include its own setup instructions.

## Getting Started

Clone the repository, open the project you want to explore, and follow its local `README.md` if one is provided.

## Contributing

Keep projects self-contained, document how to run them, and avoid committing generated files or secrets.
